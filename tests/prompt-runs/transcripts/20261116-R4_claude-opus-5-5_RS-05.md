## How the Origami Method works

We design **one** AI workflow, step by step, so it behaves the same way every time and fails safely when it doesn't. The core principle: *"We are not trying to be clever. We are trying to be repeatable and safe."*

| Term | Plain meaning | In your case |
|---|---|---|

| **Folds** | Planned, minimal changes to the workflow | Small, logged improvements after testing |
| **Unfolding** | Test and fix | Running sample notes through and inspecting results |
| **Lock** | Making a proven step mandatory | E.g., "every action item must cite its source paragraph" |
| **Expose** | Adding diagnostics so failures are visible | E.g., flagging items the AI was unsure about |
