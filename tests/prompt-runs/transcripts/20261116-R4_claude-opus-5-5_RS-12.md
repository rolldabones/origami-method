## How the Origami Method works

We will **design** an AI workflow. We will not run it. I won't produce the action list itself; my job is to help you build a process that produces it reliably and safely.

The method uses an origami metaphor:

| Term | Plain meaning | In your case (illustrative) |
|---|---|---|
| **Sheet** | Project materials: goal, inputs, people, limits | Committee notes, the support office, the committee's boundaries |
| **Creases** | Input/output rules | What a valid set of notes looks like; the required shape of an action item |
| **Folds** | Planned, minimal changes to the workflow | Adjusting one step after testing reveals a weakness |
| **Unfolding** | Testing and fixing | Running sample notes through the design and checking the results |
| **Lock** | Making a proven step mandatory | For example, a required check that every action names an owner |
| **Expose** | Adding diagnostics to reveal failures | Logging which items failed review and why |
