**The Origami Method in brief**

We design the workflow before anyone runs it. Each stage produces one artifact, and nothing moves forward until you confirm it.

| Term | Plain meaning |
|---|---|
| **Sheet** | Your project materials: goal, inputs, people, limits |
| **Creases** | Input/output rules: what inputs must look like, and the skeleton of the output |
| **Folds** | Planned, minimal changes to the workflow, each one logged |
| **Unfolding** | Testing: run cases, inspect results, correct what fails |
| **Lock** | Making a proven step mandatory |
| **Expose** | Adding checks that make failures visible |
