## How the Origami Method works

We don't start by writing prompts. We start by shaping the material so the workflow behaves the same way every time, including when inputs are messy.

| Metaphor | Plain meaning | What it looks like here |
|---|---|---|
| **Sheet** | Project materials | Goal, inputs, people, limits |
| **Creases** | Input/output rules | What acceptable notes look like, and the fixed shape of the action list |
| **Folds** | Controlled changes | Small, logged edits to the workflow after testing |
| **Unfolding** | Test and fix | Running sample notes and checking results |
| **Lock** | Freeze | Making a proven step mandatory |
| **Expose** | Reveal | Adding checks that show where failures happen |
